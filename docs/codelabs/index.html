BEFORE YOU BUILD

A clear starting point.

You should be comfortable with Python and HTTP APIs. You will learn this stack's tool and identity boundaries as you go.

For the local checkpoints

Python 3.11, a terminal and the sample files. Tests use fixtures and mocked HTTP. No Daraja credentials or model calls are needed.

For the cloud path

An approved Google Cloud project with billing, Google Cloud CLI and administrator help with IAM. Lab 2 also needs access to a supported Gemini model on Vertex AI.

What is deliberately outside the core

Payment execution is disabled. Callback reception, reconciliation, durable orders and an Apigee proxy are not deployed by these labs. Sandbox initiation is a documented optional server capability.
